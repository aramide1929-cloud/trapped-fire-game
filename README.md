# Trapped Fire

An original browser-based battle royale prototype inspired by the high-energy survival shooter genre.

## Features

- top-down survival arena combat
- shrinking safe zone
- enemy AI with ranged and melee patterns
- loot pickups for health, ammo, and upgrades
- score, ammo, health, and zone HUD
- restart flow and simple polished UI

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- Move: W, A, S, D or arrow keys
- Aim: mouse
- Fire: left mouse button
- Reload: R

## Notes

This project is intentionally original and does not copy Free Fire branding, assets, or gameplay design.
It captures the feel of a survival shooter while using custom code and art.
